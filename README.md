## Introduction
The goal of this project is to predict the results of international football matches based on features such as: `home_team`, `away_team`, `rank_difference`, `last_5_games`, `match_level`, `neutral_field`. The target variable is, as you might have guessed, `result`, which stores the final outcome that can have 3 possibilities:
-   `0` = away team win
-   `1` = draw
-   `2` = home team win

The model must learn based on the data from `train.csv` to predict the result of a match from `test.csv`.

`1. Problem Type`
-   The chosen problem is a *multiclass classification* one, because the target variable as mentioned above can take 3 values, and the model must choose between them.

`2. Dataset Structure`
-   I created, as per the requirement, 700 instances: 500 for training and 200 for testing in the final dataset, with each instance representing a match.
-   The dataset is divided into 2 subsets:
-   `train.csv` = training subset
-   `test.csv` = testing subset
-   The split was done by randomized extraction, using the `train_test_split` function from the `scikit-learn` library.
-   In addition, I used the `stratify=df["result"]` parameter to keep the distribution of the 3 possible values of the target variable balanced in both subsets, ensuring they have similar proportions of wins, draws, and losses respectively.
-   Thus, the results from the final dataset will be reflected proportionally in both the training and testing sets.

`3. Table Features`
-   The final dataset contains 8 columns, including the target column *result*.
-       home_team -> categorical string value, the home team
-       away_team -> categorical string value, the away team
-       rank_difference -> integer, the absolute difference between the rankings of the 2 teams
-       home_form_last_5 -> real number, the recent form of the home team in the last 5 matches, on a scale from 0 to 1 as this avoids large numerical values and is easy to read in a normalized form
-       away_form_last_5 -> real number, the recent form of the away team in the last 5 matches, on a scale from 0 to 1
-       neutral_location -> integer, boolean value showing if the match is on a neutral field or not (0 = no, 1 = yes)
-       importance_level -> categorical string value, indicates the type of competition the match is part of
-       result -> categorical integer value, takes 3 possible values (0, 1 or 2) 
-   I met the requirement of having at least 8 relevant columns including the target column, as well as 3 different data types (integers, real numbers, categorical values and strings).

`4. Dataset Construction Method and Saving`
-   The method chosen for building the dataset is `synthetic generation`; it does not come from an existing file but was generated by simulating fictitious international matches.
-   I imported a list of 42 countries, and for each team I assigned a rank, based on the FIFA ranking at the time of making this project.
-   For each match, a home team and an away team were generated. The rank of each team was obtained starting from its base rank, to which a small variation between -3 and +3 positions was added. This variation simulates normal fluctuations in form or ranking.
-   For each match, the following were generated:
-       recent form of the home team
-       recent form of the away team
-       whether the match is on a neutral field or not
-       the type of competition
-       internal values for the teams' offense/defense
-       expected_goals based on the features
-   Also, when generating the offense and defense, I generated values rounded to 2 decimals between `0.4 - 1` so that there are no completely weak teams. Similarly, in choosing the field, the probability is higher (`75%`) of not having neutral matches; this could be inverted considering the 2026 World Cup that is about to start :)
-   The final result was simulated using the expected_goals values and applying the Poisson distribution.
### P.S: To make the dataset closer to reality, I artificially introduced a small percentage of missing values in the `home_form_last_5`, `away_form_last_5`, and `importance_level` columns. No missing values were introduced in the target column `result`.

`5. Missing Values Analysis`
-   Following the analysis of missing values, null values were found in the following columns:
-   `home_form_last_5`
-   `away_form_last_5`
-   `importance_level`

-   In the training subset, 17 missing values were identified, meaning a percentage of 3.4% of the data. In the testing subset, 4 missing values were identified, representing 2% of the data.
-   I analyzed two strategies for handling missing values:
### 5.1 Deleting incomplete rows
-   The method is intuitive and empirical, but it can lead to data loss and dataset reduction.
-   I used the `dropna()` function which deletes rows that have at least one missing value (NaN).
### 5.2 Imputing missing values
-   This strategy is more "professional" and helps maintain the integrity of any dataset, so I relied on it for the rest of the project.
-   Being different data types, I had 2 choices depending on the data type of the values in the columns.
-   For the numerical columns `home_form_last_5` and `away_form_last_5`, the missing values were replaced with the median calculated on the training subset. I chose the median because it is more robust to extreme values.
-   For the categorical column `importance_level`, the missing values were replaced with the most frequent value from the training subset.

`10. Training and Evaluating a Baseline Model`

-   To train a model, I used `Random Forest` from the `scikit-learn` library. I chose this model because it is suitable for `multiclass classification` problems and can learn nonlinear relationships between features.
-   Before training, categorical variables were encoded into numerical variables using `OneHotEncoder`.
-   The model was trained on the train subset and evaluated on the test subset.
-   The metrics were as follows:
-      accuracy
-      precision
-      recall = how well the model detects a class
-      F1-score = precision + recall

-   As a relevant graph, I also introduced a confusion matrix that shows on the main diagonal which examples were predicted correctly and otherwise what margin of error we have. Draws are the hardest to separate and predict correctly given the low number of parameters that can lead to this circumstance.
-   Random Forest is a very good starting model, but it can be improved through additional features.
